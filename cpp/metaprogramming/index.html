Metaprogramming

Programs that manipulate programs. Parsers, compilers, interpreters are metaprograms.

It refers to the ways a program has knowledge of itself or can manipulate itself - "writing code that writes code".

Template Metaprogramming​

A technique in which templates are used by a compiler to generate temporary source code, which is then merged with the rest of the source code and compiled.

Templates are different from macros. A macro is a piece of code that executes at compile time and performs textual manipulation / replacement.

Reflection <meta> library​

Reflection is a form of metaprogramming - the program can examine information about itself, like returning a list of all the properties of an object.

Reflection vs Type Traits​

The primary difference between reflection and type traits is their scope and purpose.

Type traits inspect high-level properties of a type as a whole (e.g., whether it is an integer or const-qualified).

  • Type traits act as compile-time metadata queries that answer binary or transformation questions about a specific type.
  • Capabilities: They can tell you if T is a pointer, a class, or trivially copyable. They can strip qualifiers, like turning const int into int
  • Limitations: Type traits treat a struct or class like a "black box". A type trait can tell you that a type is a class, but it cannot tell you how many fields that class has, what they are named, or how to iterate over them.

Reflection allows deep introspection into the internal structure of a type (e.g., listing a class's member variables, function signatures, or names).

  • Reflection opens up the "black box" to look inside the structure of your code
  • Capabilities: Modern approaches—such as the static reflection features in C++26—introduce syntax like the ^ operator to capture meta-information
  • Use Case: This allows you to programmatically loop over member variables to auto-generate a JSON serializer or convert an enum value directly to its string equivalent without macros

With the advent of static reflection, type traits are shifting to become a subset of reflection functionality. Instead of relying on non-portable compiler built-ins (intrinsics) to determine type properties, standard libraries can use portable reflection operators to implement standard type traits under the hood.
