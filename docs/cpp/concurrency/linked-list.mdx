# Linked List

## Hand Over Hand Locking

- In a lock-based linked list where each node has a pointer to the next node and a mutex to protect it, we can use hand over hand locking to ensure safe traversal of the linked list 
- Basically, hand over hand locking is the technique of acquire a lock on the next node's mutex first, before releasing the mutex on the current node
