## Introduction 

Memory reclamation is essential in data structures to enable dynamic insertion and deletion of elements. Memory reclamation itself is a complex topic - determining when a region of memory has no threads referring to it and is safe to be freed. Languages like Java that have built-in automatic garbage collection help to ensure the progress of the program, but does not guarantee the progress of the garbage collector itself.

### Quiescent state based reclamation (QSBR)

- Typically used to implement RCU (read-copy-update) schemes
- Based on concept of a _grace period_
- A _grace period_ is a time interval $[a,b]$ such that after $b$, all nodes removed before $a$ can be safely reclaimed
- QSBR uses _quiscent states_ to detect grace periods 
- A _quiscent state_ for some thread T is a state in which T holds no references to shared nodes 
- A _grace period_ is any time interval in which every thread has passed through at least one quiscent state
