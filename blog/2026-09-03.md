## Concepts

- A model is really just a file embedded with weights that predicts the next token given some input
- Open Weight
    - Weights are published online, you can freely download and run locally 
    - Closed model = AI lab hides its weights and implementation and only exposes an interface through its website
- Token Compression
    - Reduce the number of input tokens to an LLM to lower costs and latency without hurting output quality 
    - It is the middleware between an app and LLM API to filter low value data before inference
- Quantization
    - A compression technique that reduces the precision of a model's numerical parameters (such as weights and activations) from high-precision formats (like 32-bit floating point) to lower-precision formats (like 8-bit or 4-bit integers) to save memory and speed up processing.
    - Maps high-precision continuous numbers to smaller, discrete values
    - Lowers memory bandwidth limits, which often bottleneck AI inference
    - Trade offs: decreases model size and hardware requirements while slightly increasing quantization error (loss of accuracy)

## Transformer Architecture 

The transformer architecture is a deep learning neural network design that processes data sequences in parallel using self-attention mechanisms instead of step-by-step recurrence.

Transformers changed deep learning by showing that sequence modeling could be built entirely around attention, without recurrence or convolution.

Core Components:
- Tokenization: Breaks raw text or input data into smaller pieces called tokens, such as words or subwords.
- Embeddings: Converts each token into a dense numerical vector that captures its semantic meaning.
- Positional Encoding: Adds position signals to the vectors so the model knows the order of tokens in a sequence.
- Self-Attention: Lets every token in a sequence communicate directly with all other tokens, calculating relationships using queries, keys, and values.
    - scaled dot-product attention
    - multi-head attention
- Feed-Forward Networks: Processes the attention outputs through multi-layer perceptrons to refine the representation of each token
- Encoder: Reads the input sequence simultaneously and builds a context-aware, rich numerical representation
- Decoder: Generates output sequences step-by-step (autoregressively) by attending to both prior outputs and the encoder's context representation
